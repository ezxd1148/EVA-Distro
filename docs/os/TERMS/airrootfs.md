# airrootfs

## What?

Airrootfs is a compressed filesystem used in Arch Linux environments,

It contains the root filesystem for the live session(KEY POINTS),

Used as the starting point for the root directory OF LIVE SYSTEM
## Why?

Allows users to run Arch Linux without installation(KEY POINTS),
  - It provides temporary environment for testing and installation process.
